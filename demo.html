5. grid-template-areas

        
Раскладка задаётся словами. Если сузить окно, карта областей меняется, а HTML остаётся тем же.

        

          
header

          
nav

          
main

          
aside

          
footer

        

        
.areas {
  display: grid;
  grid-template-areas:
    'head head head'
    'nav  main side'
    'foot foot foot';
  grid-template-columns: 10rem 1fr 12rem;
}

@media (max-width: 40rem) {
  .areas {
    grid-template-areas: 'head' 'main' 'nav' 'side' 'foot';
    grid-template-columns: 1fr;
  }
}

      


      

        
Шпаргалка

        

          
fr

          
доля свободного места

          
repeat(n, …)

          
повтор колонок или строк

          
minmax(a, b)

          
размер от a до b

          
auto-fit / auto-fill

          
сколько колонок поместится; auto-fit схлопывает пустые

          
grid-column: 1 / 3

          
от линии 1 до линии 3; span 2 — занять две

          
grid-area

          
имя области или row-start / col-start / row-end / col-end

          
justify-/align-items

          
выравнивание содержимого в ячейке (по x / по y)

          
justify-/align-content

          
выравнивание всей сетки в контейнере

          
gap

          
промежутки между ячейками
